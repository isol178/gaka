# 既知の罠

調査や実装の前に `grep -ri "<キーワード>" docs/tips/` で照合する。新しい罠を踏んだら、症状・原因・対処を1項目として追記する。

## 環境

### pnpm 12 が corepack 経由で起動しない

- **症状**: `pnpm -v` が `Cannot find module .../corepack/v1/pnpm/12.x/bin/pnpm.cjs` で落ちる
- **原因**: Node 22 に同梱の corepack が pnpm 12 のパッケージ構成に対応していない
- **対処**: `package.json` の `packageManager` で pnpm 10 系に固定している。上げるときは corepack の更新とセットで行う

### ADR の検証に PyYAML が要る

- **症状**: `validate_adr.py` が「PyYAML が必要です」で終わる
- **対処**: `pnpm adr:check` を使う（`uv run --with pyyaml` で一時的に入れて実行する）

### Biome が Markdown を書き換える

- **症状**: `biome check --write .` で `docs/*.md` や README が整形される
- **原因**: Biome 2.6 から Markdown も整形対象になった
- **対処**: `biome.json` で `*.md` と `docs` を除外している。除外を外さない

## 描画と評価

### 描画結果はプラットフォーム間で完全一致しない

- **症状**: macOS で求めたピクセルハッシュが Linux の CI で一致しない
- **原因**: Skia のアンチエイリアスや浮動小数点の差
- **対処**: テストは「同じ環境で2回描いて一致するか」で決定性を確かめる。プラットフォームをまたぐ厳密なゴールデン画像は持たない。必要になったら許容誤差つきの比較を使う

### 小さいキャンバスでは観察条件 A と B の差が出ない

- **症状**: 256px のキャンバスで、サムネイル（B）とフル画像（A）の画像トークンが同じになる
- **原因**: サムネイルの長辺が 256px なので、元画像と同じ大きさになる
- **対処**: 観察条件を比べるケースでは 1024×768 などの実寸のキャンバスを使う
